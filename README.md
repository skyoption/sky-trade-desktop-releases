# Sky Trade Desktop — Releases

Public releases and auto-update feed for the Sky Trade desktop trading
platform. Download the latest installer from the
[Releases page](https://github.com/sky-option/sky-trade-desktop-releases/releases/latest):

- **macOS**: `SkyTrade-<version>-universal.dmg` (Apple Silicon + Intel, signed & notarized)
- **Windows**: `SkyTrade-<version>-Setup.exe`
- **Linux**: `SkyTrade-<version>-x86_64.AppImage`

Installed apps update automatically from this repository.
